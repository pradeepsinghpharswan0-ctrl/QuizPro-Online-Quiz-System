About Website

QuizPro is a full stack Online Quiz Management System developed to help students practice programming and technical subjects through interactive quizzes. The platform provides category-wise quizzes, timer-based assessments, instant score calculation, answer review, leaderboard ranking, and an admin panel for managing questions. The project is built using HTML, CSS, JavaScript, Python Flask, SQLite Database, and C language integration.
