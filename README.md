# 🎯 QuizPro — Online Quiz Management System

A modern **Full Stack Online Quiz Management System** built using **HTML, CSS, JavaScript, Python Flask, SQLite, and C integration**.

QuizPro allows users to practice technical MCQ quizzes with:

* category-wise quizzes
* timer-based assessments
* instant score calculation
* leaderboard ranking
* admin panel
* animated modern UI
* responsive design

---

# 🚀 Features

## 👨‍💻 User Features

# ⚙️ How To Run The Project

## 1️⃣ Clone Repository

```bash
git clone https://github.com/pradeepsinghpharswan0-ctrl/QuizPro-Online-Quiz-System.git
```

---

## 2️⃣ Open Backend Folder

```bash
cd Bcend
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv .venv
```

---

## 4️⃣ Activate Environment

### Windows

```bash
.venv\Scripts\activate
```

---

## 5️⃣ Install Dependencies

```bash
pip install flask flask-cors
```

---

## 6️⃣ Run Flask Server

```bash
python app.py
```

Backend runs on:

```bash
http://127.0.0.1:5000
```

---

## 7️⃣ Open Frontend

Open:

```bash
Frend/index.html
```

in browser.
